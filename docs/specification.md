# 仕様と実装の範囲

## 合意した画面

- 業務ツール型．左メニュー: AIに相談，ナレッジ，問い合わせ，設計・評価．管理者には利用状況も表示．
- 起動時はログイン．未期限切れのセッションがある場合は作業画面を復元．
- メール・パスワード，表示切替，ログイン保持チェック（既定OFF）．
- 通常ログインと，社員・管理者のデモ体験を併設．
- 回答の下に出典を置き，クリックしたときだけ原文を開く．
- ブラウザー幅に合わせてメニューとサンプル質問を折り返す．

## 実装上の決定

セッションを localStorage に保存しない．保持はHttpOnly CookieとサーバーDBで管理．未選択時はCookieを永続化しないが，ブラウザーの「前回セッションを復元」機能によりCookieが復元される場合がある．サーバー側の有効期限も必ず確認する．

通常アカウントは管理者発行．一般公開のサインアップは設けない．メールによるパスワード再設定は未対応のため管理者への連絡を案内する．

デモは2時間．デモの管理者は共有文書を変更できない．自分のデモ問い合わせの状態変更は可能．ログアウト時にデモ会話と問い合わせを削除する．

通常アカウントの問い合わせはユーザーIDに紐づけ，再ログインしても残る．通常管理者は通常アカウントの問い合わせを管理できるが，デモの問い合わせは表示しない．
